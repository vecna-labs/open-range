# CLA Signatures

This **orphan** branch stores Contributor License Agreement signatures collected
by the CLA Assistant workflow (`.github/workflows/cla.yml` on `main`).

Signatures live in `signatures/version1/cla.json` and are appended automatically
when a contributor signs on a pull request.

- Do **not** protect this branch — the CLA Assistant bot pushes to it directly.
- Do **not** merge this branch into `main`. It intentionally shares no history
  with the codebase.
