# OpenRange · Living Office

A 3D isometric Sims-style visualization of an OpenRange admitted snapshot, with
LLM-driven NPCs, LLM-driven red + blue agents, and a live WebSocket-streamed
event feed.

Built to show what a *living* cyber range looks like when every persona
decision, every reaction, and every agent move is authored by a real model
(`x-ai/grok-4.1-fast` via OpenRouter) — not a scripted routine.

## Architecture

```
       Manifest (tier1_basic.yaml)
              │
              ▼  admission oracle (unchanged)
       Admitted Snapshot (store-backed, frozen)
              │
              ▼
    OpenRangeRuntime  ←  LLMGreenScheduler  (implements runtime.green.GreenScheduler Protocol)
              │                 │
              │                 ├─ PersonaForge : 1 batched LLM call → 19 unique office people
              │                 ├─ DayPlan      : 1 batched LLM call → slot-indexed intents
              │                 └─ ReactiveBus  : 1 LLM call per malicious event → in-character reactions
              │
              ├─ reducers (only event emitter, unchanged)
              ├─ RewardEngine (only grader, unchanged)
              │
              ▼
       LLMAgent(red) + LLMAgent(blue)   ← grok-4.1-fast tool-calling over 5 tools
              │
              ▼
       FastAPI + WebSocket /stream
              │
              ▼
       Three.js isometric 3D scene
       (low-poly office, desks, service buildings, speech bubbles,
        attack-line pulses, reward bars, training curves)
```

All LLM calls flow through `SeededLLM` — a disk-cached, seeded gateway. First
run pays tokens; every replay is free and byte-identical. This preserves
OpenRange's admission determinism.

## Running

```bash
source /Users/aaronbrown/Downloads/DEV/OLD/Cyber-AutoAgent/ghost/python/env_dev.sh
# OPENROUTER_API_KEY is now in the environment

# one-time: admit a snapshot (offline; ~30s)
uv run openrange admit -m tier1_basic.yaml \
  -o /tmp/demo-build \
  --store-dir /tmp/demo-snaps \
  --validation-profile graph_only

# start the server
uv run --with fastapi --with uvicorn --with httpx \
  python -m examples.living_office.server
```

Then open http://127.0.0.1:8010/ and hit **▶ Start Episode**.

## What you see

- **3D office** — zones colored (external/dmz/corp/data/management), 19 NPCs at
  desks, six service buildings with distinct low-poly shapes.
- **Speech bubbles** — in-character lines generated by grok-4.1-fast when
  personas talk in chat/email.
- **Attack lines** — colored arcs when red or blue acts (red = attack, blue =
  defend).
- **Live event ticker** — every tick, action, event, and utterance.
- **Agent thoughts panel** — each red/blue turn's one-sentence reasoning.
- **Reward bars** — red/blue/continuity, live.
- **Training curves** — SFT loss, GRPO red vs blue reward, snapshots admitted
  (canned from `training.json`).

## Framework integration

This example follows the **Concordia GM pattern** — the runtime's reducers play
the Game Master role (they remain authoritative over event emission and
grading), while the LLM authors intent and payload text. It composes cleanly
with OpenRange's admission oracle and can be swapped in for
`ScriptedGreenScheduler` via `OpenRangeRuntime(green_scheduler=...)`.

## Files

- `llm.py` — `SeededLLM` gateway
- `llm_green.py` — `LLMGreenScheduler` + `PersonaForge` + `DayPlan` + `ReactiveBus`
- `agents.py` — `LLMAgent(red|blue)` with 5-tool schema
- `server.py` — FastAPI + WebSocket, episode loop
- `static/index.html` + `static/scene.js` — Three.js 3D frontend

Not part of the core `open_range` package. Example only.
